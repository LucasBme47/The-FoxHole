# The-FoxHole
Rasp Pi 5 configured to sit inline between a wired network and router. All wired internet traffic inspected via Suricata. Qwen LLM queries AbuseIPDB, sends email alerts and chats via WebUI. PiHole ad blocking. Dashboard capability via Grafana, Prometheus, node exporter. Samba NAS. 2 Pt fwd rules for Internal-only Minecraft server (server not incl.)
